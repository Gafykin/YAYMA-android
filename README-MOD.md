# YAYMA MOD 1 — сборка и использование

Форк YAYMA 2.5.2 с тремя доработками. Версия приложения: **2.5.2-mod1 (versionCode 2002)** — отличается от оригинала, видно в списке приложений.

> Внимание: мод подписан другим ключом, чем оригинальный APK, поэтому **поверх оригинала он не установится**. Сначала удалите оригинальное приложение (данные приложения — скачивания в кэш, настройки — будут потеряны), потом ставьте мод.

---

## Что изменено

### 1. «Удалить из плейлиста» в меню •••
Внутри любого вашего плейлиста меню **•••** у трека получило пункт **«Удалить из плейлиста»** (иконка в стиле остальных пунктов). Удаление работает сразу и показывает уведомление об успехе/ошибке.

### 2. Нажатие на трек больше НЕ включает «Мою волну»
Раньше трек, запущенный из Поиска или со страницы исполнителя, после окончания затягивал за собой очередь «Моей волны» (рекомендации). Теперь трек играет один, очередь не расширяется рекомендациями. Плейлисты, альбомы и «Мне нравится» продолжают играть свою очередь, как раньше. Явный пункт «Моя волна по треку» в меню ••• работает по-прежнему.

### 3. Обход цензуры (нативная реализация FckCensor)
Плагины PulseSync (в т.ч. FckCensor) технически невозможно запустить в YAYMA — они рассчитаны на web/webpack-рантайм PulseSync. Вместо этого суть FckCensor реализована нативно:

- **Автозамена**: включается в Настройках → «Обход цензуры» → «Автозамена запикиванных треков». Приложение подтягивает список замен из комьюнити-репозитория [FckCensorData](https://github.com/Hazzz895/FckCensorData) (~1500 треков) и проигрывает оригинальные записи вместо запикованных. Список кэшируется и обновляется автоматически раз в сутки (или вручную кнопкой «Обновить список замен»).
- **Ручная замена**: в меню ••• у любого трека есть пункт **«Заменить своим файлом…»** — выберите mp3/flac/m4a, и он будет проигрываться вместо этого трека (приоритет выше всего, даже над кэшем). Пункт **«Убрать замену»** появляется, если замена установлена.

## Как собрать APK через GitHub Actions (рекомендуется)

1. Создайте на GitHub **приватный репозиторий** (или форк `darkplayoff/yayma`).
2. Загрузите содержимое этой папки в репозиторий. Через веб-интерфейс: «uploading an existing file» → перетащите все файлы/папки (включая `.github`) → Commit. Либо через git:
   ```bash
   git init
   git remote add origin https://github.com/<ВАШ_НИК>/<РЕПО>.git
   git add -A
   git commit -m "YAYMA mod1"
   git push -u origin main --force
   ```
3. Откройте вкладку **Actions** в репозитории → слева workflow **«Build Mod Android»** → кнопка **«Run workflow»** → **Run workflow**.
4. Через ~15–25 минут в завершившемся запуске появится артефакт **yayma-mod-android** — скачайте его. Внутри три APK; для большинства телефонов нужен **`yayma-android-arm64-v8a-2.5.2-mod1-dsign.apk`**.
5. Скачанный zip артефакта распакуйте, перекиньте APK на телефон и установите (разрешите установку из неизвестных источников).

APK будет подписан debug-ключом — это нормально для личного использования. Если хотите свою подпись — создайте в настройках репозитория секреты `ANDROID_KEYSTORE_BASE64`, `ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_ALIAS`, `ANDROID_KEY_PASSWORD` (см. оригинальный `build.yml`).

## Локальная сборка (альтернатива)

Нужны: Flutter (stable), Rust 1.97.1 + targets `aarch64-linux-android`, `armv7-linux-androideabi`, `x86_64-linux-android`, Android SDK/NDK, JDK 21.

```bash
flutter_rust_bridge_codegen generate   # из папки src
cd src
flutter pub get
flutter build apk --release --split-per-abi
```
